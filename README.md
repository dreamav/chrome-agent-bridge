# Chrome Agent Bridge ⚡

Ультра-легковесный, полностью автономный менеджер сессий и групп вкладок для **Google Chrome** (Manifest V3, 0% CPU, Session Buddy killer).

Работает **100% локально и автономно** прямо внутри браузера: не требует серверов, внешних зависимостей, сторонних бэкендов или ключей API.

## 🚀 Пошаговая установка в Google Chrome

1. В адресной строке Chrome перейдите на: `chrome://extensions/`
2. В правом верхнем углу включите **«Режим разработчика»** (*Developer mode*).
3. Нажмите кнопку **«Загрузить распакованное»** (*Load unpacked*) в левом верхнем углу.
4. Выберите папку расширения:
   ```text
   e:\vibecoding\chrome-agent-bridge\extension
   ```
5. Готово! Расширение появится на панели инструментов.

## 🌟 Ключевые возможности

### 1. Полноценная поддержка цветных групп вкладок (Chrome Tab Groups)
В отличие от Session Buddy и OneTab, расширение сохраняет **полную иерархию нативных групп Chrome**:
- **Цвета и названия**: сохраняются все 9 нативных цветов Chrome (`grey`, `blue`, `red`, `yellow`, `green`, `pink`, `purple`, `cyan`, `orange`) и оригинальные заголовки групп.
- **Состояние свернутости**: свернутые группы восстанавливаются свернутыми.
- **Многооконность**: сохраняются все окна браузера с точным порядком вкладок и закреплением (`pinned`).
- **Выборочное восстановление**: восстановление всей сессии, отдельного окна или конкретной группы в 1 клик.

### 2. Прямой импорт бэкапов из Session Buddy
- Поддержка нативного формата экспорта Session Buddy (`nxs.json.v2`).
- Автоматическая очистка и конвертация сотен старых сохранённых сессий.
- Экспорт и импорт чистых JSON-файлов для переноса между компьютерами.

### 3. Умное точечное переключение (Smart Switcher)
- При клике по вкладке в менеджере расширение сначала проверяет, **не открыта ли она уже** в одном из окон Chrome:
  - Если вкладка уже открыта → мгновенный фокус на неё без создания дубликатов.
  - Если не открыта → аккуратное открытие.

### 4. Интеграция с плейлистами YouTube (InnerTube API)
- Работает напрямую через нативный протокол YouTube InnerTube от имени активного пользователя браузера.
- **Поддержка бренд-каналов**: автоматический проброс сессии активного канала (`DELEGATED_SESSION_ID` и `X-Goog-PageId`).
- **В любой плейлист**:
  - Быстрое добавление в «Смотреть позже» (Watch Later).
  - Выбор любого пользовательского плейлиста активного канала из выпадающего списка.
  - Ввод ID или ссылки на плейлист (`PLxxxxxxxxxxxx`).
- **Пакетное (Batch) добавление**:
  - Выделяйте галочками вкладки (или целые окна/группы) как в сохранённых сессиях, так и в живом браузере.
  - Плавающая панель автоматически распознаёт ссылки на YouTube и активирует кнопку: `⏱️ В плейлист YouTube (N видео)`.
  - Модальное окно отображает активный канал, список плейлистов и шкалу прогресса.

### 5. Быстрое устранение дубликатов
- Анализ всех открытых окон и закрытие дубликатов в 1 клик с освобождением памяти браузера.

## 🔄 Обновление расширения после правок

1. Перейдите на страницу `chrome://extensions/`
2. Найдите карточку **«Chrome Agent Bridge»**
3. Нажмите на значок круговой стрелочки **«Обновить»** (🔄) в правом нижнем углу карточки.

## 🛡️ Безопасность и производительность (KISS)

- **0% CPU при простое**: Service Worker спит и не нагружает систему фоновыми циклами.
- **100% Offline & Local**: Никаких внешних серверов, вебсокетов или телеметрии. Все данные хранятся локально в `chrome.storage.local`.
- **Минимальные права**: Используются только встроенные API Manifest V3 (`tabs`, `tabGroups`, `scripting`, `storage`, `downloads`, `contextMenus`, `cookies`).
