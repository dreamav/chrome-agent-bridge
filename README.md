# Chrome Agent Bridge ⚡

Ультра-легковесный мост между реальным браузером **Google Chrome** и **AI-агентами** (Antigravity IDE, Claude Desktop, Cursor и др.).

Позволяет AI-ассистентам безопасно, мгновенно и с **нулевой нагрузкой на процессор (0% CPU в фоне)** управлять реальными вкладками, устранять дубликаты, организовывать рабочее пространство и считывать контент веб-страниц (включая страницы под вашей активной авторизацией).

---

## 🏗 Архитектура проекта

```
chrome-agent-bridge/
├── extension/                     # Расширение Chrome (Manifest V3)
│   ├── manifest.json              # Конфигурация MV3 с минимальными правами
│   ├── background.js              # Фоновый Service Worker (0% CPU, WebSocket клиент)
│   ├── popup.html                 # Тёмный интерфейс управления (Dark Glassmorphism)
│   ├── popup.js                   # Контроллер попапа и быстрых действий
│   └── icons/                     # Иконки расширения (16x16, 48x48, 128x128)
├── mcp_server.py                  # Локальный FastMCP-сервер (Python + WebSockets)
├── console.php                    # CLI-утилита для ручного управления (PHP 7.1+)
└── README.md                      # Инструкция и документация
```

### Принцип работы (KISS Архитектура):
* **Расширение Chrome (Manifest V3)** → чистый **ИСПОЛНИТЕЛЬ («руки»)**. Никакой захардкоженной логики и ключевых слов внутри. Прозрачный, легковесный мост к Chrome Tabs API (0% CPU).
* **Внешний AI-агент / FastMCP / CLI** → **«МОЗГ»**. Анализирует семантику вкладок и отправляет готовый макет через команду `apply_layout`.
* **Локальный WebSocket (`ws://127.0.0.1:8765`)** → мгновенная двухсторонняя связь между AI и браузером.

## 🚀 Пошаговая установка расширения в Google Chrome

### Шаг 1 → Откройте менеджер расширений
В адресной строке Google Chrome введите и перейдите:
```text
chrome://extensions/
```

### Шаг 2 → Включите «Режим разработчика»
В правом верхнем углу экрана найдите переключатель **«Режим разработчика»** (*Developer mode*) и включите его.

### Шаг 3 → Нажмите «Загрузить распакованное»
В левом верхнем углу появится панель кнопок. Нажмите:
**«Загрузить распакованное»** (*Load unpacked*) →

### Шаг 4 → Выберите папку расширения
В открывшемся проводнике перейдите в каталог проекта и выберите папку:
```text
e:\vibecoding\chrome-agent-bridge\extension
```
*(Или подпапку `extension` внутри вашей рабочей директории).*

### Шаг 5 → Готово!
Расширение **Chrome Agent Bridge** появится в списке расширений и на панели инструментов браузера.
- При клике на иконку открывается интерфейс **Dark Glassmorphism**.
- При запущенном локальном сервере статус автоматически станет: **Connected 🟢**.

## 🔌 Запуск локального MCP-сервера (Python)

Сервер работает на **Python 3.10+** и использует менеджер пакетов `uv` (все зависимости подтягиваются автоматически без загрязнения глобального окружения).

### Команда запуска:
```bash
uv run --with "mcp<2" --with "websockets" python mcp_server.py
```

### Добавление в Antigravity IDE / Claude Desktop:

Добавьте конфигурацию сервера в ваш файл `mcp_config.json`:

```json
{
  "mcpServers": {
    "chrome-agent-bridge": {
      "command": "uv",
      "args": [
        "run",
        "--with",
        "mcp<2",
        "--with",
        "websockets",
        "python",
        "e:/vibecoding/chrome-agent-bridge/mcp_server.py"
      ]
    }
  }
}
```

### Доступные MCP-инструменты для агента:

| Инструмент MCP | Назначение |
| :--- | :--- |
| `get_open_tabs()` | Получить список всех открытых вкладок во всех окнах (`id`, `windowId`, `title`, `url`, `active`, `pinned`, `groupId`) → |
| `close_tabs(tab_ids)` | Закрыть одну или массив вкладок по их ID → |
| `close_duplicate_tabs()` | Автоматически найти вкладки с одинаковыми URL и закрыть дубликаты → |
| `get_tab_content(tab_id)` | Извлечь чистый текст страницы (`document.body.innerText`) даже под авторизацией → |
| `focus_tab(tab_id)` | Активировать вкладку и перевести окно Chrome на передний план → |
| `open_tab(url)` | Открыть новую вкладку с указанным URL → |
| `group_tabs()` | Автоматически сгруппировать вкладки в цветные группы Chrome по их доменам → |
| `ungroup_all_tabs()` | Распустить все группы вкладок во всех окнах Chrome → |
| `smart_organize()` | Умная организация по 3 окнам: Окно 1 (ИИ & Сервер), Окно 2 (Vincode & Авто), Окно 3 (Вайбкодинг & Отдых) → |
| `apply_layout(groups, close_empty_windows)` | Применить внешний макет от AI-агента: перемещение вкладок и создание цветных групп → |

## 💻 Управление из терминала: CLI на PHP (`console.php`)

Утилита написана на чистом PHP (полная совместимость с **PHP 7.1+**) и не требует установки сторонних расширений или Composer-пакетов.

### Примеры команд:

```bash
# 1. Посмотреть все открытые вкладки (ID, окно, заголовок, URL):
php console.php tabs

# 2. Быстро удалить дубликаты открытых вкладок в 1 клик:
php console.php dedupe

# 3. Прочитать и вывести текст страницы по ID вкладки:
php console.php read 101

# 4. Сфокусировать окно и сделать вкладку активной:
php console.php focus 101

# 5. Открыть новую страницу:
php console.php open https://github.com

# 6. Сгруппировать вкладки по доменам в цветные группы:
php console.php group

# 7. Распустить все группы вкладок во всех окнах:
php console.php ungroup

# 8. Умная смысловая организация по 3 главным окнам:
#    • Окно 1: ИИ & Нейросети (purple) + Общение & Сервер (green)
#    • Окно 2: Vincode & Авто (cyan)
#    • Окно 3: Вайбкодинг & Карьера (blue) + Отдых, Спорт & Музыка (red)
php console.php smart-organize

# 9. Применить внешний план макета от AI:
php console.php layout plan.json

# 10. Закрыть одну или несколько вкладок:
php console.php close 102 103

# 11. Резервный режим: запуск чистого PHP WebSocket сервера:
php console.php serve
```

## 🔄 Как обновить расширение после изменений

Если расширение уже было загружено в Chrome:
1. Перейдите на страницу `chrome://extensions/`
2. Найдите карточку **«Chrome Agent Bridge»**
3. Нажмите на значок круговой стрелочки **«Обновить»** (🔄) в правом нижнем углу карточки расширения →
4. Все новые функции и команды мгновенно активируются в браузере!

## 🎨 Возможности Popup UI (Dark Glassmorphism)

При нажатии на иконку расширения в браузере открывается интерфейс со следующими функциями:
- **Индикатор статуса в реальном времени** → `Connected 🟢` / `Offline 🔴` с мягкой неоновой пульсацией.
- **Счётчик открытых вкладок** → мгновенный подсчёт общего числа вкладок во всех окнах.
- **Кнопка «Удалить дубликаты →»** → быстрый поиск и закрытие повторяющихся страниц в 1 клик.
- **Кнопка «Сгруппировать по доменам →»** → аккуратное наведение порядка и сортировка по проектам/сервисам.
- **Индикатор эндпоинта** → наглядное отображение рабочего порта `ws://127.0.0.1:8765`.

## 🛡️ Безопасность и производительность (KISS)

- **0% CPU при простое**: WebSocket-клиент расширения слушает события браузера и сервера без опросов по таймеру (no polling loops).
- **Строгая локальность**: WebSocket привязан исключительно к `127.0.0.1`, внешние подключения из сети заблокированы.
- **Никаких лишних разрешений**: расширение использует только базовые API Manifest V3 (`tabs`, `tabGroups`, `scripting`, `storage`).
- **Стрелки в интерфейсе и CLI**: оформлены исключительно эстетичным символом `→`.
